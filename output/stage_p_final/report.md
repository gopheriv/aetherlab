1. Рассинхрон речи и событий 1–20 с во всех 8 блоках → narration была
   целыми поблочными клипами, mux укладывал речь к нулю, а события (числа,
   формулы, раскрытия графиков) опаздывали → `output/stage_k2_fragments/`
   (45 фрагментов × 3 языка, lossless-join asserted), retime сценария
   (j1b 12→14, j7b 12→9, j7c 14→17, постановочные раскрытия в B0/B2–B5/B7),
   помуксовая сборка по измеренным длительностям → речь/субтитры/события
   согласованы; аудиогейт P: 45/45 кью с речью в большинстве окна.
2. B1 короче на 1 кадр (1499f) → учтено измеренными смещениями в
   `output/stage_m_final/*/assembly_manifest_*.json`, перерендер не нужен.
3. Свободные алиасы («равноускоренное движение» и др.) вели на урок v1 →
   `aetherlab/services/ent_lesson_catalog.py`: `curated_ent_lesson` ведёт все
   алиасы на v2-план; точный legacy-id `constant_acceleration` оставлен на v1,
   чтобы старые записи и прогресс продолжали разрешаться.
4. В приложении не было записи v2 и ссылок на медиа →
   `aetherlab/core/models.py` (`LessonBundle` + `srt_path`/`pdf_path`/
   `review_status`, старые кэши грузятся);
   `aetherlab/services/lesson_pipeline.py` (пребилд-бандл из фиксированных
   артефактов, при отсутствии медиа — статус `error` с целым планом);
   `aetherlab/ui/lesson_view.py` (кнопка PDF, бейдж проверки, счётчик
   субтитров); `aetherlab/ui/main_window.py` (открытие PDF, ветки
   кинематики); `aetherlab/ui/student_views.py` (hero и каталог ведут на
   `constant_acceleration_5min`).
5. BUG-266: topic-agnostic scaffold подставлял чужие формулы/ключи →
   каркас помечается `practice_scaffold_unverified` независимо от заявлений
   модели (см. diff + зелёные регрессии).

## 6. Как открыть

1. Перезапустить приложение (закрыть окно; инстанс от 20:39 не содержит код
   Этапа O), затем `python -m aetherlab` (или `physlab`) из корня репозитория.
2. Дашборд → hero-карточка кинематики → кнопка урока (или каталог тем →
   кинематика): откроется урок `constant_acceleration_5min`.
3. Переключатель языка в командной панели: ru/kk/en меняют видео, звук,
   субтитры и PDF; числа примера (14/32/25/56) сохраняются.
4. Строки оглавления (8 блоков) — seek по измеренным смещениям; кнопка PDF —
   учебный конспект; вкладка практики — H1–H5 с разбором; прогресс
   сохраняется, янтарный бейдж = ожидает учителя.
